`ros` `middleware`

ROS (Robot Operating System) is a middleware framework, not an OS in the kernel sense — it provides a publish/subscribe messaging layer, standard message types, and tooling so that independent robotics components (sensors, planners, controllers) can be developed as separate nodes and wired together instead of one monolithic program. It's the de facto standard for structuring nontrivial robotics software.
